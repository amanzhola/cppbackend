## 🗑 Исправление удаления

| Операция        | Что нужно удалить явно                  | SQL-логика                                                                                                                    | Почему так                          |
| --------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| Удаление автора | Теги книг автора → книги автора → автор | `DELETE FROM book_tags WHERE book_id IN (...)`; `DELETE FROM books WHERE author_id = $1`; `DELETE FROM authors WHERE id = $1` | Тестовая БД могла быть без каскада  |
| Удаление книги  | Теги книги → книга                      | `DELETE FROM book_tags WHERE book_id = $1`; `DELETE FROM books WHERE id = $1`                                                 | Теги не должны блокировать удаление |

```sql
DELETE FROM book_tags
WHERE book_id IN (
    SELECT id FROM books WHERE author_id = $1
);

DELETE FROM books
WHERE author_id = $1;

DELETE FROM authors
WHERE id = $1;
```

```sql
DELETE FROM book_tags WHERE book_id = $1;
DELETE FROM books WHERE id = $1;
```

## 🏷 Правила обработки тегов

| Правило               | Как реализовано                           | Зачем нужно                               |
| --------------------- | ----------------------------------------- | ----------------------------------------- |
| Убрать лишние пробелы | `normalize(raw_tag)`                      | Чтобы `dog` и `  dog  ` стали одним тегом |
| Пропустить пустые     | `if (tag.empty()) continue;`              | Чтобы `,,` не создавали пустые теги       |
| Пропустить длинные    | `if (tag.size() > 30) continue;`          | Чтобы не нарушать `varchar(30)`           |
| Убрать дубли          | `seen.insert(tag).second`                 | Чтобы тег не повторялся                   |
| Отсортировать         | `std::sort(result.begin(), result.end())` | Тесты ожидают алфавитный порядок          |

```cpp
while (std::getline(stream, raw_tag, ',')) {
    std::string tag = normalize(raw_tag);

    if (tag.empty()) {
        continue;
    }

    if (tag.size() > 30) {
        continue;
    }

    if (seen.insert(tag).second) {
        result.push_back(std::move(tag));
    }
}

std::sort(result.begin(), result.end());
```

## ⚠️ Почему длинный тег ломал EditBook

| Шаг транзакции    | Что происходило                    |
| ----------------- | ---------------------------------- |
| `UPDATE books`    | Название книги менялось            |
| `DELETE old tags` | Старые теги удалялись              |
| `INSERT new tags` | Длинный тег нарушал `varchar(30)`  |
| Ошибка PostgreSQL | Вся транзакция откатывалась        |
| Итог              | Новое название книги тоже исчезало |

Поэтому ошибка выглядела как:

```text
IndexError: list index out of range
```

Хотя настоящая причина была в откате транзакции из-за слишком длинного тега.
