# 🚗 Collision Detection and Statistics

## 📌 Описание

Этот раздел относится к Sprint 3 / Sprint 19_20 и посвящён обработке коллизий, математике пересечений объектов, статистике игрового сервера, Catch2 и отладке.

Здесь собираются мини-упражнения по настройке тестовой инфраструктуры, работе с Catch2, вычислениям столкновений объектов и анализу игровой статистики.
