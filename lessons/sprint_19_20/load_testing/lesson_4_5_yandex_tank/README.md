# 🚀 Lesson 4/5 — Yandex Tank

## 📌 Описание

Это первое практическое занятие по нагрузочному тестированию.

В отличие от профилирования, где изучается производительность отдельных функций, здесь внимание переносится на сервер целиком.

Главный вопрос урока:

```text
Сколько запросов способен обработать сервер?
```

Для этого используется инструмент:

```text
Yandex Tank
```

| 📌 Тема     | 📖 Что изучается                          | ✅ Итог                                 |

## 🔫 Почему называется Яндекс.Танк

Исторически внутри Яндекса нагрузочное тестирование сравнивали с обстрелом сервера запросами.

Отсюда появились термины:

```text
Танк
Патроны
Стрельба
Обстрел
```

---

## 👻 Что такое Phantom

Phantom — это движок генерации нагрузки.

Он создаёт большое количество HTTP-запросов к серверу.

Например:

```text
100
1000
10000
```

запросов одновременно.

---

## 📊 Что такое RPS

Полностью:

```text
Requests Per Second
```

Количество запросов за одну секунду.

Например:

```text
100 запросов за секунду
```

означает:

```text
100 RPS
```

---

## ⚙️ Архитектура Yandex Tank

Основные компоненты:

| Компонент  | Назначение                          |
| ---------- | ----------------------------------- |
| Monitoring | Мониторинг CPU, RAM, Disk и Network |
| Phantom    | Генерация HTTP-нагрузки             |
| Console    | Вывод статистики в терминал         |
| Aggregator | Сбор метрик и таймингов             |
| Autostop   | Автоматическая остановка теста      |

## 📄 Файл load.yaml

Создать:

```bash
touch load.yaml
nano load.yaml
```

Содержимое:

```yaml
overload:
  enabled: false

phantom:
  address: 127.0.0.1:8080
  ammofile: ammo.txt
  ammo_type: uri

  load_profile:
    load_type: rps
    schedule: line(5,30,1m)

  ssl: false

console:
  enabled: true

telegraf:
  enabled: false
```

---

## 🔍 Разбор конфигурации

Адрес сервера:

```yaml
address: 127.0.0.1:8080
```

Файл запросов:

```yaml
ammofile: ammo.txt
```

Тип нагрузки:

```yaml
load_type: rps
```

Модель роста нагрузки:

```yaml
schedule: line(5,30,1m)
```

означает:

```text
от 5 RPS
до 30 RPS
за 1 минуту
```

---

## 📈 Основные модели нагрузки

Линейный рост:

```yaml
line(5,30,1m)
```

Постоянная нагрузка:

```yaml
const(100,5m)
```

означает:

```text
100 RPS
5 минут
```

Ступенчатая нагрузка:

```yaml
step(100,1000,100,30s)
```

означает:

```text
100
200
300
...
1000 RPS
```

каждые:

```text
30 секунд
```

## 💣 Файл ammo.txt

Создать:

```bash
touch ammo.txt
nano ammo.txt
```

Содержимое:

```text
[Connection: close]
[Host: localhost]

/api/v1/maps
/api/v1/maps/map1
/api/v1/maps/map2
```

---

## 🔍 Что означают строки

Закрывать соединение после ответа:

```text
Connection: close
```

Имя сервера:

```text
Host: localhost
```

Запросы:

```text
/api/v1/maps
/api/v1/maps/map1
/api/v1/maps/map2
```

Каждая строка соответствует отдельному HTTP GET запросу.
