# 🚦 Load Testing

## 📌 Описание

Этот раздел посвящён нагрузочному тестированию backend-приложений.

Если профилирование отвечает на вопрос:

```text
Где программа тратит время?
```

то нагрузочное тестирование отвечает на вопрос:

```text
Сколько запросов выдерживает программа?
```

Здесь изучаются инструменты генерации нагрузки, модели тестирования, измерение RPS и анализ поведения сервера под ростом количества запросов.
