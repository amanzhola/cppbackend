# ⏱️ Lesson 5/10 — Code Instrumentation

## 📌 Описание

Мини-упражнение показывает, как вручную инструментировать C++ код для измерения времени выполнения отдельных функций.

В примере используется RAII-класс `LogDuration`: объект создаётся в начале функции, запоминает время старта, а при выходе из области видимости автоматически выводит длительность выполнения.

---

## 🧠 Что изучается

| 📌 Тема                     | 📖 Что происходит в коде                                    | ✅ Итог                                     |
| --------------------------- | ----------------------------------------------------------- | ------------------------------------------ |
| `std::chrono::steady_clock` | Используется для точного измерения времени выполнения       | Можно измерять длительность операций       |
| RAII                        | Замер начинается в конструкторе и завершается в деструкторе | Код измерения работает автоматически       |
| `LOG_DURATION`              | Макрос создаёт локальный объект `LogDuration`               | Замер добавляется одной строкой            |
| `UNIQ_ID(__LINE__)`         | Генерирует уникальное имя переменной через номер строки     | Можно использовать макрос несколько раз    |
| `std::cerr`                 | Время выполнения выводится в поток ошибок                   | Логи отделены от обычного вывода программы |

## ⚙️ Сборка через CMake

Находясь в папке упражнения:

```bash
cd ~/cppbackend/lessons/sprint_19_20/profiling_applications/lesson_5_10_code_instrumentation
```

Создать папку сборки:

```bash
mkdir -p build
cd build
```

Запустить CMake:

```bash
cmake ..
```

Собрать проект:

```bash
cmake --build .
```

---

## ▶️ Запуск

```bash
./lesson_5_10_code_instrumentation
```

---

## ✅ Ожидаемый вывод

Примерный вывод:

```text
Program started
LoadConfiguration: 40 ms
ConnectToDatabase: 90 ms
ReadDataFromDatabase: 130 ms
ProcessData: 70 ms
GenerateReport: 55 ms
ApplicationScenario: 385 ms
Program finished
main: 385 ms
```

Значения могут немного отличаться, потому что `sleep_for` и планировщик операционной системы не гарантируют абсолютно точное время.

---

## 🧪 Быстрая сборка без CMake

Можно скомпилировать напрямую:

```bash
g++ -std=c++17 main.cpp -o code_instrumentation
```

Запустить:

```bash
./code_instrumentation
```

---

## 🧠 Главная идея

Инструментирование кода помогает быстро понять, сколько времени занимает каждая часть программы.

Это первый простой шаг к профилированию: перед сложными профайлерами можно добавить локальные замеры и увидеть, какая функция работает дольше остальных.
