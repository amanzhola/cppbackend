# 🔍 Profiling Applications

## 📌 Описание

Этот раздел относится к Sprint 3 / Sprint 19_20 и посвящён профилированию приложений на C++.

Здесь собираются мини-упражнения по измерению производительности, поиску узких мест, инструментированию кода и анализу времени выполнения отдельных частей программы.

---

## 🗂 Навигация по упражнениям

| 📌 Упражнение                      | 📖 Что изучается                                                                                                                                   | 🧠 Зачем это нужно                                                            | ✅ Переход                                            |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------- |
| `lesson_5_10_code_instrumentation` | Инструментирование C++ кода через RAII-класс `LogDuration`, макрос `LOG_DURATION`, `std::chrono` и автоматический замер времени выполнения функций | Позволяет быстро находить медленные участки программы без внешнего профайлера | [README](lesson_5_10_code_instrumentation/README.md) |
| `lesson_6_10_compiler_profiler_friends` | Профилирование C++ программы через `g++ -pg`, файл `gmon.out`, отчёт `gprof`, flat profile, call graph и визуализацию через `gprof2dot + graphviz` | Показывает, как компилятор и профайлер работают вместе: компилятор добавляет профилировочный код, а `gprof` помогает найти горячие точки программы | [README](lesson_6_10_compiler_profiler_friends/README.md) |
| `instrumentation` | Практическая задача по профилированию через `gprof`: анализ трёх версий приложения (`v0`, `v1`, `v2`), поиск самых медленных функций через Flat Profile, сравнение времени выполнения и выбор наиболее производительной реализации | Показывает полный цикл оптимизации: измерение производительности, поиск горячих точек, сравнение реализаций и принятие решений на основе профилирования | [README](../../../sprint3/problems/instrumentation/solution/README.md) |
| `lesson_7_10_statistical_profiling` | Статистическое профилирование через Linux Perf: запись профиля через `perf record`, анализ отчётов через `perf report`, работа с `perf top` и поиск горячих точек без инструментирования исходного кода | Показывает современный подход к профилированию Linux-приложений на основе выборки событий процессора и позволяет анализировать реальные нагрузки без модификации программы | [README](lesson_7_10_statistical_profiling/README.md) |
