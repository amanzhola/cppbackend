# 🧪 Testing and Debugging

## 📌 Описание

Этот раздел посвящён тестированию и отладке C++ приложений.

Если профилирование отвечает на вопрос:

```text
Где программа тратит время?
```

а нагрузочное тестирование отвечает на вопрос:

```text
Сколько запросов выдерживает сервер?
```

то тестирование отвечает на вопрос:

```text
Работает ли программа правильно?
```

Здесь изучаются фреймворки модульного тестирования, написание юнит-тестов, повторное использование тестового кода, разработка через тестирование (TDD) и отладка приложений.
