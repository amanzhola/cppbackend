# 🔑 Keys, Indexes and Transactions

## 📌 Описание раздела

Раздел посвящён проектированию надёжной структуры PostgreSQL: типам данных, ключам, индексам, ограничениям и транзакциям.

| 📌 Направление             | 📖 Что изучается                                                               | 🧠 Зачем это нужно                                                      | ✅ Итог                          |
| -------------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------- | ------------------------------- |
| Типы данных                | `integer`, `bigint`, `SERIAL`, `UUID`, `varchar`, `text`, `bytea`, `timestamp` | Помогает правильно выбирать типы полей для реального backend-приложения | Таблицы проектируются осознанно |
| Безопасность пользователей | `pgcrypto`, `crypt()`, `gen_salt('bf')`, хеширование паролей                   | Позволяет не хранить пароли в открытом виде                             | Пароли сохраняются как хеши     |
| Ключи                      | `PRIMARY KEY`, `FOREIGN KEY`, уникальность и связи таблиц                      | Обеспечивает целостность данных                                         | Таблицы связаны корректно       |
| Индексы                    | Индексация часто используемых полей                                            | Ускоряет поиск и фильтрацию данных                                      | Запросы работают быстрее        |
| Транзакции                 | `BEGIN`, `COMMIT`, `ROLLBACK`                                                  | Защищает данные от частичных изменений                                  | Операции становятся атомарными  |
