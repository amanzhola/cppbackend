## 🧠 Что такое транзакция

Транзакция — это группа операций, которая должна выполниться полностью либо не выполниться совсем.

Схема:

```text
START TRANSACTION
        ↓
несколько SQL-команд
        ↓
COMMIT
```

или

```text
START TRANSACTION
        ↓
несколько SQL-команд
        ↓
ROLLBACK
```

---

## 🧠 Зачем нужны транзакции

Представим банковский перевод:

```text
Снять деньги со счёта A
↓
Добавить деньги на счёт B
```

Если сервер упадёт между этими операциями:

```text
деньги исчезнут
```

Транзакция защищает от подобных ситуаций.

## ACID

| Буква | Расшифровка | Значение                                 |
| ----- | ----------- | ---------------------------------------- |
| A     | Atomicity   | Всё или ничего                           |
| C     | Consistency | База остаётся корректной                 |
| I     | Isolation   | Незавершённые изменения скрыты от других |
| D     | Durability  | После COMMIT изменения сохраняются       |

## 🧪 Практика №2 — COMMIT

Цель:

```text
Показать, что изменения внутри транзакции
не видны другим клиентам до COMMIT.
```

---

### Терминал №1

Подключение:

```bash
psql \
-h localhost \
-p 30432 \
-U postgres \
-d postgres
```

Выполнить:

```sql
START TRANSACTION;

UPDATE accounts
SET funds = funds + 50
WHERE name = 'Shura';
```

Пока НЕ выполнять:

```sql
COMMIT;
```

---

### Терминал №2

Подключение:

```bash
psql \
-h localhost \
-p 30432 \
-U postgres \
-d postgres
```

Проверка:

```sql
SELECT * FROM accounts;
```

Результат:

```text
Shura = 0
```

Изменения ещё не видны.

---

### Возвращаемся в Терминал №1

Подтверждаем транзакцию:

```sql
COMMIT;
```

---

### Снова Терминал №2

Повторяем:

```sql
SELECT * FROM accounts;
```

Теперь увидим:

```text
Shura = 50
```

---

## Что произошло

| Шаг                      | Состояние                                   |
| ------------------------ | ------------------------------------------- |
| UPDATE внутри транзакции | Изменение видно только текущему подключению |
| До COMMIT                | Остальные клиенты изменений не видят        |
| После COMMIT             | Изменения становятся видны всем             |

## 🧪 Практика №3 — ROLLBACK

Цель:

```text
Показать отмену изменений.
```

---

### Подключение

```bash
psql \
-h localhost \
-p 30432 \
-U postgres \
-d postgres
```

---

### Выполнение

```sql
START TRANSACTION;

UPDATE accounts
SET funds = funds + 100
WHERE name = 'Panikovsky';
```

Проверяем внутри той же транзакции:

```sql
SELECT * FROM accounts;
```

Увидим:

```text
Panikovsky = 100
```

---

### Отмена

```sql
ROLLBACK;
```

---

### Проверка

```sql
SELECT * FROM accounts;
```

Снова:

```text
Panikovsky = 0
```

---

## Что произошло

| Шаг            | Результат                             |
| -------------- | ------------------------------------- |
| UPDATE         | Изменение появилось внутри транзакции |
| ROLLBACK       | Все изменения отменены                |
| После ROLLBACK | База вернулась к исходному состоянию  |

---

## Сравнение COMMIT и ROLLBACK

| Команда    | Что делает          | Можно отменить позже |
| ---------- | ------------------- | -------------------- |
| `COMMIT`   | Сохраняет изменения | Нет                  |
| `ROLLBACK` | Отменяет изменения  | Не требуется         |

---

## Полезные команды

| Команда                   | Назначение                   |
| ------------------------- | ---------------------------- |
| `START TRANSACTION;`      | Начать транзакцию            |
| `COMMIT;`                 | Подтвердить изменения        |
| `ROLLBACK;`               | Отменить изменения           |
| `SELECT * FROM accounts;` | Посмотреть текущее состояние |
| `\d accounts`             | Показать структуру таблицы   |
| `\dt`                     | Показать список таблиц       |
