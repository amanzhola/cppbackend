# 🐘 PostgreSQL

## 📌 Описание раздела

Раздел посвящён изучению PostgreSQL и его использованию в backend-разработке.

PostgreSQL является одной из самых популярных реляционных СУБД и широко применяется для хранения данных серверных приложений.
