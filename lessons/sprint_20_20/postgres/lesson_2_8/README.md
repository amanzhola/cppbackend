## 🐳 Запуск PostgreSQL через Docker

Команда запуска контейнера:

```bash
sudo docker run -d \
--name postgres16 \
-p 30432:5432 \
-e TZ=UTC \
-e POSTGRES_PASSWORD=postgres \
postgres:16
```

Схема подключения:

```text
WSL Ubuntu
│
├── psql
│
└── Docker
    └── PostgreSQL 16
```

---

## 💻 Установка клиента

Установка:

```bash
sudo apt update
sudo apt install -y postgresql-client
```

Проверка:

```bash
psql --version
```

Результат:

```text
psql (PostgreSQL) 16.14
```

---

## 🔌 Подключение к серверу

Команда подключения:

```bash
psql \
-h localhost \
-p 30432 \
-U postgres \
-W
```

Пароль:

```text
postgres
```

После успешного подключения:

```text
postgres=#
```

---

## 📋 Проверочные команды

| Команда             | Назначение                |
| ------------------- | ------------------------- |
| `\conninfo`         | Информация о подключении  |
| `\du`               | Список ролей              |
| `\l`                | Список баз данных         |
| `SELECT version();` | Версия сервера PostgreSQL |

---

## 🧠 Что означают параметры подключения

| Параметр | Расшифровка | Назначение              |
| -------- | ----------- | ----------------------- |
| `-h`     | Host        | Адрес сервера           |
| `-p`     | Port        | Порт подключения        |
| `-U`     | User        | Пользователь PostgreSQL |
| `-W`     | Password    | Запросить пароль        |

---

## 👤 Роль postgres

Команда:

```sql
\du
```

Показала:

```text
postgres
```

Основные права:

| Право       | Назначение               |
| ----------- | ------------------------ |
| Superuser   | Полный доступ            |
| Create Role | Создание ролей           |
| Create DB   | Создание баз данных      |
| Replication | Репликация               |
| Bypass RLS  | Обход Row Level Security |

---

## 🗄 Базы данных PostgreSQL

Команда:

```sql
\l
```

Обычно показывает:

```text
postgres
template0
template1
```

## 🐳 Управление контейнером

Проверить контейнер:

```bash
sudo docker ps
```

Остановить:

```bash
sudo docker stop postgres16
```

Запустить:

```bash
sudo docker start postgres16
```

Логи:

```bash
sudo docker logs postgres16
```

Удалить:

```bash
sudo docker rm -f postgres16
```
