# 💾 Serialization

## 📌 Описание раздела

Раздел посвящён сериализации объектов C++ и сохранению состояния приложения.

Сериализация позволяет:

```text
объект в памяти
↓
архив
↓
файл / строка / сеть
```

Десериализация выполняет обратную операцию:

```text
архив
↓
восстановление объекта
↓
объект в памяти
```

В спринте используется:

```text
Boost.Serialization
Conan
CMake
```
