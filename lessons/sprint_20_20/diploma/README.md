# 🎓 Diploma

## 📌 Описание раздела

Раздел посвящён финальной подготовке backend-проекта: проектированию базы данных для игры, сохранению статистики игроков, таблице лидеров, интеграции PostgreSQL и финальной сборке дипломного решения.

| 📌 Направление     | 📖 Что изучается                              | 🧠 Зачем это нужно                                       | ✅ Итог                                  |
| ------------------ | --------------------------------------------- | -------------------------------------------------------- | --------------------------------------- |
| Проектирование БД  | Таблицы, поля, ограничения, индексы           | Позволяет хранить игровые данные после завершения сессии | Данные игроков сохраняются в PostgreSQL |
| Игровая статистика | `name`, `score`, `play_time_ms`               | Позволяет строить таблицу лидеров                        | Рекорды игроков доступны после игры     |
| UUID               | `gen_random_uuid()`, `uuid PRIMARY KEY`       | Позволяет использовать независимые идентификаторы        | ID можно создавать без `SERIAL`         |
| Индексы            | Сортировка по `score`, `play_time_ms`, `name` | Ускоряет получение leaderboard                           | Таблица лидеров читается эффективно     |
| Diploma            | Финальная интеграция                          | Собирает знания спринта в итоговое решение               | Подготовка к финальной задаче           |
