# 🎯 Gather Tests

## 📌 Описание

Задача посвящена написанию набора тестов для функции:

```cpp
std::vector<GatheringEvent> FindGatherEvents(
    const ItemGathererProvider& provider
);
```

Особенность задания заключается в том, что реализацию функции писать не нужно.

Необходимо написать только тесты, которые смогут отличить корректную реализацию алгоритма поиска столкновений от ошибочных вариантов.

## 🧠 Что изучается

| Тема                | Что проверяется                |
| ------------------- | ------------------------------ |
| Геометрия           | Поиск столкновений объектов    |
| Catch2              | Написание модульных тестов     |
| Boundary Cases      | Проверка граничных условий     |
| Chronological Order | Сортировка событий по времени  |
| False Positives     | Отсутствие лишних столкновений |
| Multiple Gatherers  | Работа нескольких сборщиков    |

---

## ⚠️ Важная особенность задания

В `precode` функция:

```cpp
FindGatherEvents(...)
```

не реализована.

Поэтому локальная сборка может завершаться ошибкой линковки:

```text
undefined reference to collision_detector::FindGatherEvents(...)
```

Это ожидаемое поведение.

Во время проверки система подставляет собственные реализации функции и запускает тесты против них.

---

## 🧪 Какие сценарии покрывают тесты

### 1. Корректное обнаружение столкновений

Проверяется:

```text
сборщик движется по прямой
предмет лежит на траектории
```

Ожидается:

```text
событие найдено
```

---

### 2. Отсутствие ложных столкновений

Проверяются случаи:

```text
предмет до начала движения
предмет после конца движения
предмет слишком далеко от траектории
```

Ожидается:

```text
события отсутствуют
```

---

### 3. Неподвижный сборщик

Проверяется случай:

```text
start == end
```

Ожидается:

```text
события отсутствуют
```

---

### 4. Хронологический порядок

Проверяется, что события возвращаются:

```text
по возрастанию времени столкновения
```

Например:

```text
0.2
0.5
0.7
```

---

### 5. Граничные случаи

Проверяются столкновения:

```text
в начальной точке
в конечной точке
ровно на границе радиуса подбора
```

Все они должны считаться корректными.

## 🔧 Исправление Dockerfile

Во время локальной проверки могла возникать ошибка:

```text
Current Conan version (1.53.0) does not satisfy the defined one (>=1.54.0)
```

Исправление:

```dockerfile
pip3 install conan==1.59.0
```

вместо:

```dockerfile
pip3 install conan==1.53.0
```

## 🔧 Добавление geom.h

В некоторых версиях прекода отсутствует:

```text
src/geom.h
```

При этом:

```cpp
#include "geom.h"
```

используется в:

```cpp
collision_detector.h
```

Поэтому файл необходимо добавить в solution.

Минимальная версия:

```cpp
#pragma once

namespace geom {

struct Point2D {
    double x = 0.0;
    double y = 0.0;
};

}
```
